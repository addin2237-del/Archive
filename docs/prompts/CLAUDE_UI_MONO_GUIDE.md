# 아키로(ARCHI LAW NOTES) UI 구현 가이드

> 목적: ChatGPT가 먼저 확정한 시안을 Claude Code가 **디자인 변경 없이** React + Vite + TypeScript로 옮기는 작업입니다. 이 단계에서는 실시간 AI 응답, MCP, 법령 API를 연결하지 않습니다.

## 1. Claude Code에 전달할 지시문

```
당신은 디자이너가 아니라 프론트엔드 구현 담당자입니다.

현재 폴더에 있는 `archilaw-apple-ui.html`을 먼저 전체 읽고,
해당 파일을 유일한 시각적 디자인 원본(Source of Truth)으로 사용하세요.

목표:
- HTML 프로토타입을 React + Vite + TypeScript 컴포넌트 구조로 이식합니다.
- PC 1536px와 모바일 390px에서 원본의 레이아웃, 색상, 타이포그래피, 여백,
  모서리 둥글기, 카드 크기, UI 순서를 그대로 유지합니다.
- Claude가 다른 스타일로 '개선', '정리', '재해석'하는 것을 금지합니다.
- 로그인, 멀티테넌시, 클라우드 서버, 결제, 광고, 사용자용 대시보드를 추가하지 않습니다.
- 법제처 API/MCP/AI API를 이 단계에서 연결하거나 가짜로 작동하는 것처럼 표현하지 않습니다.

디자인 잠금 규칙:
1. 사이드바 / 상단바 / 히어로 / 검색창 / 답변 카드 / 법령 탭 / 우측 계산기 /
   최근 질문 / 하단 용어 카드의 전체 구조를 유지합니다.
2. CSS 변수(색상), 폰트 굵기, 그림자, 반응형 브레이크포인트를 원본에서 그대로 사용합니다.
3. 독자적인 관리자 페이지 스타일, 원본에 없는 유채색 버튼, 기본 HTML 테이블, 불필요한 그라데이션을 추가하지 않습니다.
4. 아이콘은 원본 인라인 SVG를 그대로 사용하거나 시각적으로 일치하게 복원합니다.
5. 예시 답변과 실제 법령 조회 결과를 시각적으로 구분하고, 'UI 시연 모드'와 경고 문구를 유지합니다.

기능 잠금 규칙:
- 질문 입력 및 Enter 제출(Shift+Enter는 줄바꿈)
- 추천 질문 선택
- 답변 탭 3개 전환
- 시연용 주제별 답변 전환
- 북마크 저장/삭제 및 로컬 저장
- 질문 히스토리 로컬 저장
- 건폐율 단순 계산(입력값 유효성 검사 포함)
- 복사 버튼
- 라이트/다크 모드
- 모바일 레이아웃 및 화면 가로 스크롤 방지

구현 방법:
- 신규 폴더에서 Vite + React + TypeScript 프로젝트를 생성합니다.
- Sidebar, Header, Hero, QuestionSearch, AnswerCard, SourceTabs,
  CoverageCalculator, HistoryPanel, GlossaryCards 컴포넌트로 분리합니다.
- 예시 답변 데이터는 별도 모듈로 관리하고, 이후 백엔드 응답으로 치환할 수 있게 인터페이스를 정의합니다.
- localStorage 오류 발생 시에도 앱이 중단되지 않도록 예외 처리합니다.
- 모바일, 태블릿, 데스크톱에서 직접 동작을 검증합니다.
- 가능한 경우 Playwright로 1536×1030, 390×844 화면 캡처를 비교합니다.
- 화면의 시각적 변경이 필요하다고 생각되면 먼저 이유를 보고하고 승인 전에는 변경하지 않습니다.

완료 조건:
1. 원본과 동일한 화면임을 비교 캡처로 증명합니다.
2. 위 사용자 동작들이 전부 정상 작동합니다.
3. 타입체크, 빌드, 콘솔 오류 0건을 확인합니다.
4. 위 결과를 먼저 보고하고, API/MCP 연결 단계는 요청이 있을 때만 진행합니다.

구현 전 파일 분석 및 컴포넌트 분리 계획을 간단히 보고한 다음 작업을 시작하세요.
```

## 3. 디자인 기준 — MONO / Apple-inspired

이 파일이 최종 확정 전 **모노톤 UI 시안**입니다. 초록색 사용 금지. 색상 변경 시 먼저 사용자에게 확인하세요.

| 항목 | 값 |
|---|---|
| 전체 배경 | `#F5F5F7` (쿨 화이트) |
| 카드 배경 | `#FFFFFF` |
| 텍스트 | `#1D1D1F` (그래파이트) |
| 헤더·히어로 | `#17191F` → `#363E4F` 그레이 그라데이션 |
| 버튼 | `#1C1D22` (차콜) |
| 보조 포인트 | `#5E7DDE` (절제된 블루) |
| 기본 모서리 | 카드 19px, 히어로 25px, 검색창 21px |
| 데스크톱 사이드바 | 247px |
| 반응형 기준 | 1240px, 1000px, 760px, 400px |
| 다크 모드 | 흑연계 다크 그레이, 대비 유지 |
| 아이콘 | 외부 리소스 없는 인라인 SVG |

UI 규칙: 기존 HTML의 스타일은 CSS 상단 + 최하단 `ARCHI LAW / MONO` 오버라이드가 합쳐져 적용됩니다. React 이식 시 **최종 계산 스타일(computed style)**이 일치해야 합니다. 이전 초록색 시안으로 되돌리지 마세요. 데스크톱/모바일 캡처 비교가 필수입니다.

## 4. 범위 경계

이번 1차는 **UI 시안 구현 단계**입니다. 서류 심사나 인허가 판단에 사용하는 프로그램이 아닙니다. 법률 예시 답변은 UI 시연 데이터이므로 운영 기능으로 전환하기 전에 실제 법령 API 조회·출처 검증·시행일·조례 적용 여부·실패 처리 방식을 구현해야 합니다.
