# ARCHI LAW / AI 모델 및 토큰 비용 관리 UI 확장 가이드

**용도:** ChatGPT가 디자인한 개인용 아키로 Apple-style UI를 Claude Code Sonnet이 정확히 React로 이식할 때 필요한 구현 명세.

## 디자인 원본 및 범위

- 최종 디자인 원본: `archilaw-apple-budget-ui.html`
- 비교 이미지: `archilaw-budget-desktop.png`, `archilaw-budget-mobile.png`, `archilaw-budget-dark.png`
- 기반 UI 디자인 규칙은 `CLAUDE_UI_MONO_GUIDE.md`를 따름.
- 현재 HTML은 **시연용**. AI API 호출, 실제 법제처 데이터, 실제 청구·결제는 전혀 연결되지 않음. 샘플 토큰 수·샘플 단가는 가상 데이터임.
- 초록색 UI로 회귀하지 말고, 원본의 그래파이트·실버·블루 디자인을 유지.

## Phase 1 - UI 이식(추천: Claude Sonnet)

1. `archilaw-apple-budget-ui.html` 전체를 읽고 컴포넌트화하되 원본과 동일하게 구현한다.
2. 검색창 하단 AI 모델 선택기, 우측 AI 사용량/비용 카드, 월 예산 입력, 토큰 상세표, 50/80/100% 경고를 구현한다.
3. 선택 모델: Gemini 무료, Groq 무료, OpenRouter 무료, Ollama 로컬, 유료 AI 샘플. **이 단계에서는 모델명이 UI 예시일 뿐이며 실제 연결을 주장하지 않는다.**
4. `샘플 질문 1회 사용량 반영`은 실제 결제를 실행하지 않고, 브라우저 시연 상태만 갱신한다. 명확한 샘플 표시 유지.
5. 모바일 390px, 데스크톱 1536px, 다크모드로 캡처 비교. UI 수정은 사용자의 사전 승인 없이 하지 않는다.
6. 기존 검색 예시·계산기·북마크·답변 탭의 모든 시연 동작 보존.

## Phase 2 이후 - 실제 공급자 연동 설계(이번 Phase에는 구현 금지)

- `AIProvider` 공통 인터페이스: `generate({question, sourceExtracts, sourceMetadata, policy, maxOutputTokens}) -> {answer, usage, provider, model, sources, tier, error}`.
- 공급자 어댑터: `GeminiFreeAdapter`, `GroqFreeAdapter`, `OpenRouterFreeAdapter`, `OllamaLocalAdapter`, `PaidAdapter`. 모델 ID는 공급자가 지원하는 현행 ID를 설정에서 조회하거나 구성값으로 관리하고, 고정 코딩된 오래된 ID에 의존하지 않는다.
- `usage`: API 실제 응답의 입력 토큰·출력 토큰·추론 토큰·캐시 읽기/쓰기 토큰·도구 과금 항목. 업체별 중복 계수 규칙을 확인하고 정규화한다. `status`, `timestamp`, `requestId`, `pricingVersion`, `costUSD`, `fxRate`, `costKRW`를 SQLite에 저장. 업체의 공식 사용량 또는 결제 내역과 차이 발생 시 "추정치"로 표시.
- **API 키는 로컬 Node.js 백엔드 환경변수나 안전한 설정 저장소에만 저장**. React HTML/클라이언트 번들 및 localStorage에 절대 포함하지 않는다.
- 비용 공식(일반형): `(일반 입력 토큰 × 입력 단가 + 출력(추론 포함) 토큰 × 출력 단가 + 캐시 관련 추가 비용 + 도구 비용) ÷ 1,000,000`, 이후 USD/KRW 환율 적용. 모델별 캐시·추론 토큰 정산 정의에 맞춰 계산하며 *중복 계산 금지*.
- 공급자 가격표에는 모델 ID, 요금제, 단가, 통화, 발효일, 업데이트 출처를 기록. 가격표가 오래됐거나 API 사용량 정보를 받지 못했다면 "계산 불가/추정" 표기. 0원으로 처리하면 안 됨.
- 무료 API: 모델 비용 0원. 그러나 토큰과 RPM/TPM/RPD 등 무료 할당량을 추적하고 한도 도달 시 429 에러 표시. 다른 무료 공급자로의 전환은 명시적으로 구성하되 **유료 공급자로 자동 전환 금지**.
- 무료 모델 사용 시 공식 법령 원문과 조문을 인용·검증. 법령 조회 실패나 출처 누락 시 AI의 법령 추측 답변 사용 금지.
- 원문만 보는 경우 AI 호출 0번, 사용료 0원. 자주 묻는 동일 질문은 원문 시행일, 갱신 시점, 조례 범위 등을 키에 포함해 캐시(법령 갱신 시 무효화).

## 월 예산 규칙(실제 백엔드 필수)

- 기본 월 예산 KRW 10,000원. 사용자가 변경 가능.
- 월 사용량 50%: 안내, 80%: 주의, 100%: 유료 요청 차단. 월 경계는 Asia/Seoul 기준으로 명시하고 업체 정산 시간과 차이 가능성을 알림.
- 요청 **전** 입력 토큰 예측 + 출력 토큰 최대치 + 도구 호출 예상 비용을 확인하여 예산 초과 위험 요청 차단. 요청 **후** 실제 토큰 사용량으로 정산. 동시 요청이면 예약 금액을 원자적으로 관리해 초과를 방지.
- 유료 요청의 실제 금액은 공급자 정산과 시차 또는 차이가 있을 수 있으므로 "앱 기준 사전 차단"이지 공급자 청구 금액에 대한 절대 보증이 아니라고 표시. 가능하면 공급자 자체 결제 예산/하드 리밋도 함께 설정.
- 예산 경고는 실제 사용량으로 발생, 임계치 1회 안내(동일 임계치 중복 알림 방지), 월별 리셋. 실시간 UI 알림을 우선하며 이메일/OS 푸시는 별도 기능.
- 기본 정책: 무료 모델 우선. 무료 모델 할당량 소진 -> 다른 무료 모델 또는 명시적 유료 전환 승인 모달. 유료 자동 결제/자동 모델 업그레이드 금지.

## 보안·개인정보 주의

- 무료 Gemini API는 무료 계층 입력·출력이 제품 개선에 사용될 수 있다고 공식 가격표에 명시. 현장 주소, 건축주 성명, 계약서 또는 비공개 사업 정보는 무료 클라우드 API에 보내기 전에 경고하고 마스킹/로컬 Ollama 대안을 제시.
- Ollama 로컬 모델도 법령 정확도를 보증하지 않으므로 "공식 원문 + AI 해설" 구조 유지.
- MCP는 **법령 검색을 수행하는 도구 인터페이스**이지 무료 LLM 제공자가 아니다. MCP 호출만으로 유료 해설 비용이 절감되는 것은 아님.
